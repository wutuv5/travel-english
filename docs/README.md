## 状态约定

- **已确认**：用户明确选择的需求。
- **建议**：为了使开发可执行而提出，仍可修改，不等于用户已批准。
- **待验证**：有官方能力或技术依据，但尚未在目标设备、免费签名和本项目组合中通过实测。
- **后续增强**：不阻塞第一版核心功能。

## 当前结论

用户已接受 SwiftUI 原生 iOS App；Windows 编辑代码，云端 macOS 构建，Windows 免费签名安装。未签名构建产物的重签流程、系统翻译在免费签名条件下的可用性尚未实测，不能视为已落地。

已确认默认规则：每日 10／15／20 分钟三档；每个练习保留最近一次未收藏录音；备份默认仅含学习记录，可选附带收藏录音。全体用户共用的月度云端请求预算为 100 元提醒、200 元停止新请求，具体计量和不可控费用边界见技术规范。

用户已选择免费签名。离线功能仍受整个 App 的签名有效期约束；旅行一周以内也不等于一定覆盖整个旅程，须以出发时剩余有效时间为准。

核心方案以 0.2 版为开发基线；用户已明确指示开始开发，无需重复请求同一授权。已创建原生翻译验证页、工程规格、云端构建工作流与 IPA 打包脚本，推送至用户提供的仓库。首次云构建已通过并生成待重签 IPA，详见首次构建指南。未创建后端或模型服务账号。G1 的编译打包部分通过，免费签名安装与 G2 真机离线翻译尚未验证，按关卡约定暂不扩展全部课程和在线业务。

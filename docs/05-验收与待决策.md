# 验收、风险与待决策

版本：0.2｜2026-10-30｜核心路线与默认规则已确认；尚未执行验收，不存在已通过项目。

## 1. 第一优先验证关卡

G1 构建与安装：从 Windows 发起 macOS 构建，得到真机 IPA，用免费账号经 Windows 工具安装到 iPhone 14；记录工具、系统、签名身份与权限。失败则先解决安装链，不扩展业务开发。

G2 核心离线翻译：在免费签名的实际 App 内准备中文和英文资源；飞行模式、强制退出并重开后，用未预存的句子完成双向翻译。验证系统接口、资源下载、存储变化和错误提示。不得用系统翻译 App 的成功代替本产品成功。

G3 在线学习链：完成一节样例课的录音、识别、角色对话、语音播放、专门发音评测及总结，记录真实费用和延迟；评分与转写分开验收。

G4 续签与数据：同账号续签、安装新版本后确认记录保留；模拟到期无法打开后的恢复流程；导出备份、在干净安装中恢复。不得默认覆盖安装绝对保留数据。

G1～G4 未通过，不将候选框架标记为已验证。任何更改免费签名、离线翻译硬需求的方案都需重新与用户确认。

## 2. 功能验收清单

- AC-01：8 类共 24 课，每课具备已约定的词句、示范对话、跟读和任务；中英文、音频逐条对应，无失效资源。
- AC-02：每日推荐 10～20 分钟，可自由进入课程，退出后能继续；后台停留不计为有效学习时长。
- AC-03：听力默认先播放，不自动显示中英文答案；可分别展开，支持重复播放。
- AC-04：录音可回听，在线返回实际评分与问题词；无声音、权限拒绝及服务失败均有正确提示；不显示音素级界面。
- AC-05：按住录音、松开发送；任务有目标、可提前结束和重练；不会连续重复发送同一轮；正常结束给出总结。
- AC-06：收藏、薄弱项、自评与复习状态在重启后保存；用户能移除误标项。
- AC-07：准备资源后，飞行模式下将新输入中文译为英文、英文译为中文；不访问在线模型；缺少资源时明确提示。
- AC-08：已下载课程、示范音频与本地录音在飞行模式重启后仍能使用；未下载音频不伪装已可离线。
- AC-09：下载中断后可重试，文件校验失败不标记完成，存储不足不破坏旧包或进度。
- AC-10：无学习账号可独立记录；导出恢复保留进度、收藏与复习；可选录音备份的范围准确。
- AC-11：iPhone 管理入口能更换服务配置并测试，不向普通用户泄露厂商密钥；设备撤销生效。
- AC-12：免费签名更新与覆盖安装、到期恢复的实际步骤有记录；出发前检查手册可由用户执行。
- AC-13：全体用户合计月度用量达到 100 元时管理员界面提醒；达到 200 元或预占将超额时拒绝新云端请求；并发、重试与跨月场景不会绕过检查。本地课程、翻译和录音回听继续可用。

## 3. 建议翻译验收集

中文到英文和英文到中文各至少 20 条，覆盖机场、酒店、餐厅、交通、购物、景点、租车和应急，包括未出现在课程中的新句子。核对否定、数字、日期、金额、地点、过敏表达与基本请求意图。

建议由用户和具备英语能力的协助者审核，至少 90% 句子保留核心意图；关键否定、金额和求助信息错误需逐项分析，不能只用总平均掩盖。具体阈值为建议，尚未获得用户确认；机器翻译质量不保证完美。

## 4. 可靠性与隐私验收

网络断开、服务超额、超时、重复点击、麦克风拒绝、来电中断、后台切换、磁盘不足均需测试。后端不得成为开放模型代理，日志不得包含密钥或原始敏感录音。

在线服务失败不阻止本地课程和翻译；离线不触发自动上传积压录音。备份不含服务访问凭据。临时音频处理与厂商保留策略应有可核查说明。

性能值在技术规范中属于建议目标，需记录实测设备、系统、文本长度、网络、模型与资源准备状态后再确认，不以模拟器结果代替真机离线结果。

## 5. 主要风险

免费签名到期是整个 App 不可用的系统限制，不会因离线模式消失。旅行一周以内仍必须核对剩余有效期。

仅 Windows 无法完成官方 iOS SDK 的最终构建；需云端或协助者 Mac。云端调试不如本地 Xcode 直接，须预留构建等待与远程排错时间。

系统翻译语言支持、地区、下载和免费签名能力组合未实测；评分服务的账号、区域、收费及网络可用性未验证。亲友机型不同需单独核对。

两个参考仓库许可信息不足，不把可公开浏览等同于可自由复制。

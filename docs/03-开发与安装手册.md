# 开发与安装手册草案

版本：0.2｜2026-10-30｜首选路线已确认；流程设计稿，不是已经验证可直接执行的安装教程。

## 1. 开发流程

1. 核心需求与首选技术路线已获用户接受，按 0.2 版基线开发；用户已明确授权开始。
2. 用户明确授权后，进行最小技术验证：构建、免费签名、iPhone 14 安装、离线中英双向翻译。
3. 验证在线录音、ASR、TTS 和发音评测，比较实际质量、延迟与账单。
4. 开发一个完整样例课，验证整个学习闭环，再扩展到 24 课。
5. 完成资源下载、复习、备份、管理员配置和错误处理。
6. 先由本人实测，再邀请 1～2 位亲友，最后扩至 5～10 人。
7. 依据实测重写正式安装手册，记录工具版本、截图、故障恢复和验收结果。

每步通过后再进入下一步，不先做全部界面再检查硬需求。G1/G2 所需验证代码和构建配置已建立，尚未实际云构建或安装；执行入口见 [首次构建与实机验证](06-首次构建与实机验证.md)。

## 2. 所需条件

- Windows 电脑，可由用户协助亲友安装和每周续签。
- USB 数据线与目标 iPhone，手机可解锁并信任这台电脑。
- 每位用户自己的 Apple 账号与本人完成的认证；不收集账号密码到应用后台。
- 云端 macOS + Xcode 构建渠道或可协助构建的 Mac；不要求用户购买 Mac。
- 服务端托管账号及所选模型服务账号；这些与苹果免费签名分开计费。
- 目标设备型号和确切 iOS 版本登记表，仅本地用于兼容与维护，不混入学习记录备份。

## 3. 构建渠道候选

首选评估 GitHub Actions macOS runner。Windows 提交源码，云端 Xcode 生成真机产物，下载后由 Windows 签名安装。私有仓库的额度、计费及可用 runner 在开通时核验，不承诺云构建永久免费。

应先验证关闭构建阶段签名后能否生成正确的真机 App，并打包为可被安装工具重签的 IPA。构建成功不代表系统能力已可用，必须继续做真实安装与离线测试。

Xcode 工程、构建脚本、签名所需权限的精确配置在开发阶段验证后交付；本次不创建这些文件。不把证书私钥、Apple 密码上传到公共仓库或流水线日志。

## 4. Windows 安装候选：Sideloadly

依据工具官方说明设计，具体安装前再次核对版本与依赖。Sideloadly 属于第三方工具，不是苹果官方 Windows 开发套件。

1. 从 [Sideloadly 官网](https://sideloadly.io/) 获取工具，按当前官方说明安装 Windows 设备连接依赖。不要未经检查批量卸载现有 Apple 软件。
2. 用 USB 连接 iPhone，解锁并信任电脑，确认工具识别目标设备。
3. 选择对应版本 IPA，由手机所有者使用自己的 Apple 账号完成签名认证；不在聊天、后台或文档中保存其密码。
4. 安装后按系统提示信任开发者；如系统要求，开启设置中的开发者模式并完成重启确认。
5. 打开 App，检查版本和本地存储；首次录音时授权麦克风。
6. 通过邀请配置应用服务访问资格，不需要注册学习账号。
7. 在 App 内准备中文、英文翻译资源，下载所需课程，完成飞行模式测试。

工具限制与自动刷新条件见 [官方 FAQ](https://sideloadly.io/faq)。若账号认证或系统升级导致安装失败，先记录错误，不更改为付费或第三方售卖证书路线。

## 5. 每周续签

免费描述文件通常自签发起 7 天有效；以实际签名信息为准，不从第一次打开 App 起算。最多 3 个免费签名应用和免费账号设备限制见 [Apple 说明](https://developer.apple.com/help/account/basics/about-your-developer-account)。亲友分别签名，不能由一个免费账号覆盖全部 5～10 人。

建议每 5～6 天安排一次维护，留出失败重试时间；这只是建议，不创建自动提醒。续签不应要求重新编译代码，新版本发布时才重新构建；具体工具行为需验证。

- 续签前导出最新学习备份，确认收藏录音的导出范围。
- 使用相同账号、稳定的应用标识和正确版本进行覆盖刷新，避免卸载。
- 完成后打开应用，确认进度、录音和课程下载仍存在。
- 若工具自动刷新，电脑必须运行且手机可通过 USB 或配置后的同网 Wi-Fi 被发现；自动刷新不是无条件成功保障。
- 更换签名账号、工具或应用标识前先备份；验证身份变化对容器和 Keychain 的影响。

到期不能打开时连接电脑重新签名，优先覆盖恢复；只有确认必要并备份后再卸载。不能把“重签一定保留数据”写成交付保证。

## 6. 出发前检查

出发当天尽量刷新，记录实际剩余有效期，必须覆盖预计返程并留出合理余量。旅行一周以内仍有临界时间风险；若不能覆盖且途中无法续签，本 App 无法保证全程可用。

检查中英模型已准备、课程已下载、录音能回听、备份已导出。在飞行模式下强制退出并重开 App，输入新中英文句子双向翻译，播放音频，确认不是仅当前页面缓存可用。

本产品不能在签名到期后从自身内部续签或提供离线功能；不承诺通知可以绕过系统限制。

## 7. 管理员操作目标

交付时提供可在 iPhone Safari 打开的管理入口；登录后配置厂商服务、测试连接、查看不含敏感内容的用量、生成亲友邀请、撤销设备和调整额度。默认使用已确认的全体用户月度 100 元提醒、200 元停止新云端请求阈值；普通用户不能修改。普通用户界面不展示厂商密钥。

托管平台的首次开通、支付与身份认证由账号所有者完成，手册给出逐步操作。具体平台尚未选择，不能提前给出虚构菜单或可用地址。

## 8. 每次发布交付物

带版本号和校验摘要的 IPA、源代码版本、构建环境记录、变更说明、安装与重签说明、备份格式版本、已知限制、实机验收记录。正式手册须依据实际成功路径补充截图。

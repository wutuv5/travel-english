## 1. travelEnglishLearn

[仓库](https://github.com/shouwokun/travelEnglishLearn)

读取：`README-前端版.md` 全文、`app.js` 中语音和存储相关片段；目录包含 HTML、CSS、JavaScript、词汇数据和旅游内容 Markdown。

已核实使用 `window.speechSynthesis` / `SpeechSynthesisUtterance` 朗读，`localStorage` 保存设置和学习记录。README 描述分类词汇、显示答案、自评和本地记录；发音评分列在后续计划中，不能当作已实现。

参考价值：分类词句、隐藏答案、示范朗读、简单进度记录。它的离线描述不等同于本项目要求的“任意输入中英文本的本地翻译”；浏览器语音的离线可用性也需按设备与音色实测。

许可状态：README 声称 MIT，但本次目录树未发现对应 LICENSE，GitHub license 元数据为空。暂只参考设计思想，不直接复制代码或课程内容；如计划复用，应先核对完整许可授权。

## 2. vocab-practice

[仓库](https://github.com/linjiang90-code/vocab-practice)

读取：`audio-engine.js`、`mastery.js`、`gen_audio.py`；另核查仓库目录。默认分支为 master。

已核实：

- 音频引擎从 `audio/s<ID>.mp3` 读取文件，使用 Web Audio 解码，提供播放和循环等能力。
- 掌握度使用自评操作，尝试请求 `/api/mastery`，并使用本地存储保存部分状态。不是专业语音发音评测。
- `gen_audio.py` 使用 `edge_tts` 生成示范 MP3；目录包含日学习页面、复习页面、语料数据、音频和 Python 工具。

参考价值：预生成音频、词句稳定 ID、自评复习与每日学习组织。原项目是 Web 页面及相关工具组合，不能直接当成原生 App。音频源码注释中的浏览器兼容结论未独立验证，不作为本项目技术保证。

许可状态：本次目录树未发现独立 LICENSE，GitHub license 元数据为空。暂不直接复用代码、音频和语料。项目的音频生成方式也不自动等同于可用于本产品的正式语音 API 服务与授权。

## 3. 可行性结论

两个项目说明旅游英语词句学习和复习可由简单 Web 技术实现，适合借鉴学习流程。它们未为本项目提供已经核实的完整实现：设备端任意中英翻译、基于录音的发音评分、统一密钥配置、原生免费签名维护。

因此不建议直接复制后套壳。建议围绕本需求建立清晰数据模型，课程内容重新编写并审核。离线翻译首选评估系统 Translation API；发音评分使用专门评测服务。

## 4. 费用估算口径

用户规模 5～10 人，每人每天 10～20 分钟，按 30 天计算，总学习时长为 **25～100 小时/月**。这是修订后的范围，之前 50～100 小时对应每天固定 20 分钟。

学习时长不等于收费音频时长。阅读、本地翻译、已下载音频回放和录音回听不按次调用云模型。

用于预估的建议假设：每 15 分钟学习中，3 分钟提交评分、2 分钟提交对话语音、2 分钟新生成 AI 音频，其余为阅读、示范、思考与回听。不是已观测数据。

在上述假设下：

- 评分音频约 5～20 小时/月。
- 对话转写约 3.3～13.3 小时/月。
- 新生成对话语音约 3.3～13.3 小时/月；若按字符收费，必须用实际英文字符数换算，不能直接把分钟当字符计费。
- 对话模型按输入及输出 token 计费，须包含重复发送的历史上下文、总结与纠错，不仅计算最后一句。

公式：月运行费 = ASR 时长×单价 + 评测时长×单价及附加项 + TTS 字符数×单价 + 输入/输出 token 费 + 托管、存储与流量。首次课程音频生成、云构建和域名另列。

可核查的单价示例：百炼价格页华北 2 CosyVoice 列有按万字符计费的型号，例如 cosyvoice-v2 为 2 元/万字符。这里仅说明计费口径，不锁定型号或地区。Azure 评测基础费用与标准语音识别口径关联，韵律评分可能额外收费。最终采用地区、税费、账户报价、免费额度到期和厂商存储规则需在开通前核对。

用户已确定预算规则为 **每月 100 元提醒、200 元停止新云端请求**，覆盖全体用户。此前 200～500 元/月的规划建议不再作为预算标准。当前尚无真实用量账单，无法保证该预算支持所有人每天完成全部在线练习。暂不依赖限时免费额度来承诺长期成本。先完成一节样例课，用真实用量乘以人数和天数形成低、中、高使用估算；如超预算，提出缩短在线对话、缓存示范音频或更换服务的方案供选择，不自动加价。

后台按已确认的阈值提供提醒与全局停止新请求的开关，配合用量预占和并发控制；账单存在延迟，不能保证零超支。托管、构建、存储和流量与可拦截的模型请求费用分列，200 元不代表这些全部费用的绝对封顶。

免费开发签名只免除付费开发者计划年费，不免云服务、构建或语音费用。首次资源下载数百 MB 是用户可接受上限量级，不是已测包体。

# 0.1.1 交互修复

用户已完成免费签名安装、信任及开发者模式启用，App 已能启动。G1 的安装启动部分有用户截图佐证。用户报告资源检查、资源准备无明显反馈，输入后翻译不可用，以及键盘无法收起；G2 离线翻译尚未通过。

## 本次修改

- 资源检查立即显示正在检查，结束显示状态和检查时间；重复点击重新发起检查，不忽略点击，不与翻译按钮互相锁定。
- 每次资源准备或翻译打开独立任务页，持有不可变请求和非空配置，从可见页面启动系统 TranslationSession；不再通过父页面可变的可选 request 守卫触发。
- 有效输入即可点翻译，不再依赖上次检查的 installed 状态。系统 translate 自行请求缺少的语言资源；不接入网络翻译服务或预存译文。
- 显示进度、取消、错误及重试。系统长时间未响应时给出等待说明，避免无反馈；用户可关闭后重新发起。
- 添加 FocusState、导航栏完成按钮、键盘工具栏收起按钮和滑动收起。点击翻译、资源准备或清空时结束输入。
- 绿色主操作按钮、圆角卡片、分段方向切换和独立结果卡片，支持系统配色和字体；不复制 Duolingo 商标、角色或课程素材，不添加虚构积分。

## 验证边界

旧资源检查返回相同状态时没有可见变化是已确认的交互缺陷；旧翻译按钮被 installed 门槛禁用是代码可确认的逻辑。下载弹窗未出现的根本原因没有设备日志，任务持有方式调整属于针对性修复，是否完全解决需真机验证。

云端加入两项 XCUITest：输入后收起键盘、无已下载资源时按钮仍可用；点击准备打开可关闭的任务页。模拟器不支持真正的 Translation 翻译，不能用这些测试证明离线能力成功。

## 覆盖安装后检查

1. 保持原签名账号和应用标识，用 0.1.1 覆盖安装，不要先卸载。
2. 点击检查状态，应立即有进度文字，随后有检查时间。
3. 点击准备资源，应进入独立页面，并看到系统下载确认、完成说明或具体错误；已下载不重复弹窗。
4. 输入“你好”后可点翻译，键盘收起并进入任务页；翻译完成后主页面显示译文。
5. 点击导航栏完成或键盘收起按钮，确认键盘消失；清空后翻译按钮禁用。
6. 准备两个方向后，飞行模式关闭 Wi-Fi、强制退出重开，用未翻译过的新句子双向测试。

如果失败，请提供任务页显示的错误域、错误码和 iOS 确切版本；不需要提供 Apple 密码或验证码。
